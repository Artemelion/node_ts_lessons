О проекте

Node Academy — это учебный проект, созданный для практики серверной разработки на Node.js.

Мы не используем Express, layout, шаблонизатор или отдельный CSS-файл. Каждая страница является самостоятельным HTML-документом.

Главная страница открывается по адресу /, а эта страница открывается по адресу /about.

Вернуться на главную

Цель проекта

Понять, как работает сервер: как он принимает запросы, обрабатывает их и отправляет ответ в браузер.

Страницы

В проекте есть только две страницы: главная и страница “О нас”. Обе страницы оформлены в одном стиле.

Следующий шаг

Позже можно добавить отдельный CSS, обработку форм, POST-запросы, JSON и переход на Express.

Как работает переход

1. Пользователь нажимает “О нас”

Браузер переходит по ссылке /about.

2. Сервер получает GET-запрос

Node.js проверяет req.url и понимает, какую страницу нужно отправить.

3. Сервер отдаёт HTML

Для /about сервер читает файл src/pages/about.html и отправляет его браузеру.
