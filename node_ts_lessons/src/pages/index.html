Node.js + HTML + CSS

Маршруты

Сервер проверяет адрес запроса. Например, путь / открывает главную, а путь /about открывает страницу “О нас”.

HTML-файлы

Страницы лежат в папке src/pages и отдаются браузеру как обычные HTML-документы.

Inline CSS

Пока стили находятся прямо внутри HTML в теге style. Это удобно для простого учебного проекта.
